# Third-party kernel

`fast-attnres==1.0.0` is pinned to the public release built from commit
`ce0881dc4a075a82b841c8e1c2f3b0a5a9e3faf9` under the MIT license.

The adapter calls only `attnres.attnres(...)`. Active package versions and
loaded source hashes are recorded in training checkpoints and evaluation
reports.
